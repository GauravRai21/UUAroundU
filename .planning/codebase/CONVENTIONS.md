# Coding Conventions

**Analysis Date:** 2026-05-06

## Code Style

- strict TypeScript
- Next.js 16 conventions (App Router, Server Components)
- Tailwind CSS v4 for styling

## Naming

- **Components:** PascalCase
- **Files/Folders:** kebab-case
- **Variables/Functions:** camelCase

## Patterns

- Use `"use client"` directive when React hooks or browser APIs are needed
- Keep state management lightweight (React Context)

## Error Handling

- Rely on Next.js `error.tsx` boundary conventions (planned)
