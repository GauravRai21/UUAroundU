Build a full-stack web application called "CampusConnect" — a hyperlocal social networking platform inspired by Nextdoor, but focused on college communities.

TECH STACK:

* Frontend: React (with clean modern UI, responsive design)
* Backend: Node.js with Express
* Database: MongoDB
* Authentication: JWT-based login system

CORE FEATURES (MVP):

1. User Authentication:

   * Register and login with email and password
   * Restrict users to join only via college email domain (e.g., @college.edu)
   * Store user info: name, email, college

2. Posts Feed (Hyperlocal):

   * Users can create posts (text + optional image)
   * Each post is tagged with the user’s college
   * Feed should ONLY show posts from users in the same college
   * Show posts in reverse chronological order

3. Interactions:

   * Like/unlike posts
   * Comment on posts
   * Display number of likes and comments

4. Backend APIs:

   * Auth APIs: register, login
   * Post APIs: create post, get feed, like post, comment on post
   * Use proper REST structure and middleware for authentication

5. Database Schema:

   * Users collection (name, email, password hash, college, createdAt)
   * Posts collection (userId, content, image, college, likes, createdAt)
   * Comments collection (postId, userId, text, createdAt)

6. Security:

   * Hash passwords using bcrypt
   * Protect routes using JWT middleware
   * Validate all inputs

7. UI Requirements:

   * Clean dashboard with feed
   * Create post component
   * Like and comment buttons
   * Minimal but modern design

OPTIONAL (if supported):

* Image upload using cloud storage (e.g., Cloudinary)
* Basic error handling and loading states

OUTPUT REQUIREMENTS:

* Generate complete backend and frontend code
* Include folder structure
* Include setup instructions (npm install, env variables, run commands)
* Ensure code is modular and production-ready
* Add comments in code for clarity

GOAL:
A working MVP that demonstrates a hyperlocal, college-based social network similar to Nextdoor, suitable for showcasing in a developer portfolio.
